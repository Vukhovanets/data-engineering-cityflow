# Правила приймання та валідації даних (Lab 02)

- **Типи та NULL:** бізнес-ключі у форматі `TEXT` (порожні відхиляються), `quantity` — `INTEGER > 0`, грошові суми — `NUMERIC(12,2) >= 0`, дати — `TIMESTAMPTZ` (UTC). Необов'язковий `phone` допускає `NULL`.
- **Дати та час:** приймається ISO 8601 з часовим поясом та `DD/MM/YYYY HH:MM` (UTC). Наносекунди зберігаються у `stg` як `TEXT`, при перенесенні у `core` округлюються до мікросекунд.
- **Валюти та товари:** дозволені лише `UAH`, `USD`, `EUR` (значення з пробілами відхиляються без автовиправлення). Активний товар (`is_active = true`) із ціною `<= 0` відхиляється; для неактивного дозволено `0.00`.
- **Дублікати та конфлікти:** точні дублікати за бізнес-полями отримують статус `duplicate` (залишається перший запис); при однаковому ключі з різними бізнес-значеннями відхиляється вся група (`KEY_CONFLICT`).
- **Зовнішні ключі:** перевіряються каскадно (`merchants/customers` -> `products/orders` -> `order_items`). Посилання на відхилений або відсутній батьківський запис відхиляється.
- **Публікація:** повний snapshot через атомарний `TRUNCATE` + `INSERT` усіх 5 таблиць `core` у межах однієї транзакції.
